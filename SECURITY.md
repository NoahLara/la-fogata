# Security Policy

La Fogata is an anonymous space for people going through hard nights, so we take security and privacy seriously.

## Reporting a vulnerability

Please report vulnerabilities **privately** through GitHub security advisories:

1. Go to the repository's **Security** tab.
2. Click **Report a vulnerability**.
3. Describe the issue, how to reproduce it, and its potential impact.

Do not open a public issue or pull request for a security problem.

We will acknowledge your report, keep you updated while we investigate, and credit you in the advisory if you wish.

## Scope

Of particular interest:

- Anything that exposes personal data or links a session to a person.
- Anything that causes content a person burns to be sent to or stored on the server.
- Bypasses of moderation or rate limits.
